** Configuration **

Créer un fichier ENVIRONNEMENT (sans extension au format JSON)
contenant le détail des adresses mail sous forme de tableau
auxquelles l'application peut se connecter.

Exemple de fichier ENVIRONNEMENT :
[
    {
        "IMAP_SERVER": "imap.host.com",
        "USERNAME": "username@host.com",
        "PASSWORD": "password"
    },
    {
        ...
    },
    ...
]
